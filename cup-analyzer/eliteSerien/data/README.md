# 数据目录

| 文件 | 说明 |
|------|------|
| `s22.js` | 球探序号 22 的赛程数据；完成爬虫配置并抓取后生成 |
| `l22.js` | 联赛让球盘路数据；有来源数据后维护 |
| `bs22.js` | 联赛大小球盘路数据；有来源数据后维护 |
| `td22.js` | 联赛进球时间数据；有来源数据后维护 |
| `球队与序号对照表.md` | 从 `s22.js` 的 `arrTeam` 核对球队序号 |
| `冠军赔率.md` | 记录有来源的冠军赔率 |
| `降级赔率.md` | 记录有来源的降级赔率 |

未取得来源数据前不创建空的统计 JS 文件，也不填入推测的球队或赔率。

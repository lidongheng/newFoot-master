# 西甲数据目录

球探体育联赛序号：**31**。

| 文件 | 用途 |
|------|------|
| `s31.js` | 赛程与积分榜，由 `npm run crawl:schedule:laliga` 更新 |
| `l31.js` | 亚盘盘路，由同一赛程爬虫更新 |
| `bs31.js` | 大小球盘路，由同一赛程爬虫更新 |
| `td31.js` | 入球时间分布，由同一赛程爬虫更新 |
| `config.json` | 球员位置映射和球队来源映射；20 条球队映射已按提供的数据写入 |
| `球队与序号对照表.md` | 球探球队序号，依据 `s31.js` 中的球队数据维护 |
| `冠军赔率.md` | 有来源与采集时间的冠军及欧战赔率记录 |
| `降级赔率.md` | 有来源与采集时间的降级赔率记录 |

赛程数据更新后，还会同步到 `crawler-server/match_center/s31.js`。

# 西甲分析项目方案

## 项目范围

在 `laLiga/` 建立与 `epl/` 同级的西甲分析模块，复用联赛赛前、赛中和赛后流程。球探体育联赛序号为 **31**，赛程数据文件为 `s31.js`。

## 实施状态

| 任务 | 状态 | 说明 |
|------|------|------|
| 创建模块目录与分析框架 | 已完成 | 目录结构对齐 EPL 联赛模块 |
| 注册赛程爬虫配置与命令 | 已完成 | `CUP_ANALYZER_CUP=laLiga`，球探序号 31 |
| 生成当前赛季赛程与盘路数据 | 待执行 | 在 `crawler-server/` 运行 `npm run crawl:schedule:laliga` |
| 填充球队与来源映射 | 已完成 | 按提供的 20 条记录写入 `data/config.json`；生成赛程后再核对球队序号 |
| 建立球队画像与赛季素材 | 待整理 | 不从 EPL 复制球队、新闻或历史报告 |

## 数据约定

- 球探赛季段按爬虫配置使用 `2026-2027`；本地报告目录使用 `26-27/`。
- 赛程文件：`data/s31.js`。
- 盘路文件：`data/l31.js`、`data/bs31.js`；入球时间文件：`data/td31.js`。
- 球队序号以当季赛程数据为准；缺少来源数据时保持未填写。

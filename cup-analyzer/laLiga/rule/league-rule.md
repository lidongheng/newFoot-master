# 西甲联赛规则概要

具体赛制、同分排序和欧战席位以西甲联盟及欧足联当赛季官方规则为准。每季分析前核对规则变化。

## 联赛赛制

- 西甲为俱乐部国内联赛，按当季官方赛程进行主客场联赛。
- 胜、平、负积分按当季官方规则记录；常规积分制为胜 3 分、平 1 分、负 0 分。
- 参赛球队、比赛轮次及同分排序以当季官方规则和赛程数据为准。

## 欧战与升降级

- 欧冠、欧联和欧会杯席位可能受当季欧战成绩及国内杯赛结果影响，分析时核实最终席位分配和顺延方式。
- 升降级名额及升班球队以当季官方规则和赛季结束结果为准。

## 分析提示

- 单场联赛按当场积分和联赛排名评估，不按杯赛两回合总比分计算。
- 争冠、欧战资格和保级形势应结合直接交锋、剩余赛程和实际积分差。
- 欧战与国内杯赛赛程、休息间隔、轮换和伤病应纳入赛前评估。

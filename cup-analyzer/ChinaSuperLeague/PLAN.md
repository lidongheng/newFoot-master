# 中超目录说明

| 目录 | 用途 |
| --- | --- |
| `data` | 联赛配置、赛程、盘路、球队序号和冠军赔率 |
| `basicData` | 球队基础数据 |
| `description` | 球队背景补充 |
| `squad` | 生成的大名单 |
| `squad-final` | 人工审核后的名单与伤停 |
| `teamProfile` | 球队画像 |
| `news` | 赛前素材 |
| `report` | 按 `2026/round-N` 存放赛前报告 |
| `postMatchSummary` | 按 `2026/round-N` 存放赛后复盘 |

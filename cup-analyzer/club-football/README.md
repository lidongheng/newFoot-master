# 俱乐部足球对象域

这里保存俱乐部球队对象和中立比赛对象。共享爬虫、分析器与理论方法仍保存在 `crawler-server` 和 `methodology`，不复制到每支球队。

- `teams/<slug>/team.json`：球队稳定身份；
- `teams/<slug>/seasons/<season>`：球队在一个赛季中的状态、分析和记忆；
- `matches/<matchId>`：双方共享的比赛事实与原始市场快照。

现有赛事目录处于兼容迁移期。它们继续承载赛事规则和尚未迁移的历史资料，但深度球队的新产物不再写回赛事级球队画像目录。

详细目录、文件职责和维护规则见：[目录结构说明.md](./目录结构说明.md)。

# 法甲数据（data）

球探体育联赛序号 **11**。

| 文件 | 说明 |
|------|------|
| `s11.js` | 赛程与积分榜等；由 `npm run crawl:schedule:ligue1` 更新 |
| `l11.js` | 亚盘盘路榜 |

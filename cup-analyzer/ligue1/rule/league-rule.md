# 法甲联赛规则（概要）

> 规则以对应赛季 LFP 与 UEFA 官方公布为准。以下赛制信息按 2026/27 赛季官方资料整理。

## 联赛赛制

- 18 支球队参加单一联赛组别。
- 每队与其他球队进行主客场双循环，共 34 轮。
- 胜 3 分、平 1 分、负 0 分；积分相同时的排序规则按当季官方章程核对。

## 欧战资格

- 欧冠、欧联和欧协联席位及其递补路径受 UEFA 当季分配、法国杯和欧洲赛事冠军资格影响。
- 每赛季开始前，按官方确认的席位表更新 `strategy/european-qualification.md`；不要把固定名次当作跨赛季不变规则。

## 升降级

- 2026/27 赛季官方日历安排法甲第 16 名与法乙升级附加赛胜者进行两回合升降级附加赛。
- 直接降级名额、附加赛对手及赛程，按当季 LFP 规则与公告确认。

# 亚冠精英联赛数据

| 文件 | 用途 |
|------|------|
| `config.json` | `positionMap` 位置映射；`team` 按懂球帝球队 ID 保存名称及球探球队序号 |
| `c192.js` | 球探 192 的赛程、阶段、球队与积分数据 |
| `l192.js` | 亚盘盘路 |
| `bs192.js` | 大小球盘路 |
| `球队与序号对照表.md` | 本赛季 36 支球队（含资格赛）的球探、懂球帝名称及序号 |
| `冠军赔率.md` | 记录有来源和采集时间的冠军赔率 |

在 `cup-analyzer/crawler-server` 执行：

```bash
npm run crawl:schedule:acle
```

使用球探 `2026-2027` 赛季，写入本目录的 `c192.js`、`l192.js`、`bs192.js`，并同步赛程至 `crawler-server/match_center/c192.js`。杯赛爬虫不生成 `td`。

球队映射于 2026-11-23 根据当季球探 `arrTeam` 与懂球帝公开搜索结果核实。资格赛出局球队保留映射，36 条映射不代表 36 支正赛球队；联赛阶段为 32 队。
